## Dataset

### Источник

- **Датасет**: Spotify User Behavior for Churn Analysis
- **Платформа**: Kaggle
- **Ссылка**: [https://www.kaggle.com/datasets/nabihazahid/spotify-dataset-for-churn-analysis/data](https://www.kaggle.com/datasets/nabihazahid/spotify-dataset-for-churn-analysis/data)
- **Размер**: ~750 KB, 8,000 записей, 12 признаков

### Описание

Датасет содержит данные о поведении пользователей Spotify для прогнозирования оттока (churn prediction).

### Ключевые признаки

- **Демографические данные**: пол, возраст, страна
- **Информация о подписке**: тип подписки
- **Поведение при прослушивании**:
  - время прослушивания
  - количество песен в день
  - процент пропусков (skip_rate)
  - количество рекламы в неделю
  - оффлайн-прослушивание
- **Технические данные**: тип устройства
- **Целевая переменная**: `is_churned` (1 - ушел, 0 - остался)

## Ход работы и улучшение модели

### Текущее состояние модели

На начальном этапе была реализована модель градиентного бустинга со следующими результатами:

#### Метрики производительности:
- **F1-score**: 0.193
- **Accuracy**: 0.70
- **Precision (class 1)**: 0.32
- **Recall (class 1)**: 0.16

#### Параметры модели:
```python
{
    'model__subsample': 0.1,
    'model__random_state': 42,
    'model__n_estimators': 700,
    'model__max_depth': 4,
    'model__learning_rate': 0.06
}
```
#### **Анализ текущих проблем**
- Низкий F1-score (0.193) - модель плохо предсказывает отток
- Низкий recall для класса 1 (0.16) - пропускает много реальных случаев оттока
- Дисбаланс классов в предсказаниях

#### **План улучшений**
- Снизить дисбаланс классов (74% vs 26%)
- Попробовать PCA и убрать "country" что позволит значительно снизить разреженность признаков после OHE
